# S31 翻译界面

界面参考根目录的 `device-translation-flow.zh-CN.html`，使用 LVGL 在 800×480 RGB/GT1151 上原生实现。浅蓝背景、圆形首页入口、青紫黄场景卡片和音量/亮度面板均由本地控件绘制。

首页显示系统时间、实际 Wi-Fi 状态和输出音量。时间未初始化时显示占位；电量显示 `--`，亮度标为演示控件。亮度滑动只改变演示值，不代表硬件调光。

- 媒体翻译接入现有 `v2vt/listen`：板载麦克风拾音，云端翻译，板载扬声器播放。默认中文 → 英文。
- 面对面与会议互译保留设置预览，开始按钮显示“功能待开放”，不会创建业务会话。
- 实时页、全文和历史页使用固定中英示例，明确标记“演示字幕”。它们不接收实时识别/翻译文本，也不表示实际声音的内容。

媒体流程为：首页 → 场景入口 → 媒体设置 → 语言选择 → 连接中 → 实时翻译。连接中可取消；实时页提供暂停/继续和更多菜单。菜单可查看固定字幕、调整音量、结束翻译或结束后更换语言。停止完成以 SDK/服务端确认结果为准，再显示完成或返回设置。

语种选择使用 SDK 公开的同一份 15 语言清单，同语种互选禁用。仅空闲时一次提交并保存完整语言对；提交接受后锁定源语言、目标语言及开始入口，收到该语言对回读或实际失败后再开放，无关音量更新和本地等待超时不会提前解锁。提交未被接受时可立即重试。活动会话修改语言前先确认结束。音量滑条拖动时预览位置，松手提交一次绝对值，最终百分比取硬件回读；实体音量键继续可用。读取失败显示 `--`，控制周期会重试恢复。

暂停保留 RTC 父会话和采集方向，以原 60 ms 节奏上行静音 MIC/reference 帧；独立停止播放方向并清除 SDK 和驱动中的旧 PCM。继续前同步工作任务、清除积压并恢复播放，成功后才更新为运行。该操作保持已保存的音量，不是云端会话结束。

配网、配对码、断网、启动拒绝、停止失败、未知启动结果等真实工作流采用统一样式。点击结束立即显示结束中；清理失败允许重试结束。服务端确认 `ended` 且本地清理记录成功移除后，SDK 清除临时清理提示，UI 显示完成页；取消或结束后更改设置则返回设置页。未知启动结果禁止创建新会话。取消期间迟到的启动成功仍保留停止入口，不能由页面返回绕过待清理状态。明确拒绝、本地音频恢复和存储错误会继续显示，不因停止成功而被抹除。

SDK 公开 `mybot/mybot_ui.h` 提供有界、非阻塞、按值复制的参数命令及语言清单。语言选择直接使用该接口检查提交结果；音量、暂停和按键事件继续经现有输入工作任务转发，业务均由 SDK control owner 处理。接受入队不等于业务已完成，显示以 LCD 状态快照回读为准。旧附件代次和失效手势不能延后执行。RGB、触摸、I2C 所有权及双 PSRAM 帧缓冲沿用现有驱动。

20/28/40 px Noto Sans SC 字库由 `scripts/generate-lvgl-font.py` 使用已登记的源字体生成，只包含页面、固定示例和语言名称需要的字符。字体保持 SIL OFL 许可；界面无需在线字体、网页脚本或图片解码器。

主机回归覆盖页面导航、演示场景、语言/音量/暂停命令、迟到启动、清理/未知状态、控件删除、内存失败及字形；`tests/media_pause` 验证媒体门控和缓冲所有权。实际显示、触摸和暂停音频仍需真机验收。烧录与业务说明见[独立听译](LISTEN_TRANSLATION.zh-CN.md)。
