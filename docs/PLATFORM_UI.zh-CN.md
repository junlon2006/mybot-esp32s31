# Mosaico 翻译界面

当前目标为 ESP-Mosaico CoreBoard V1.2 的 480×480 显示屏。共享 LVGL 页面采用原生尺寸排版：场景入口纵向排列，语言设置和选择保留双列，实时字幕使用整行宽度，面对面底部保留两个发言语言按钮。字体保持 20/28/40 px，所有交互区域至少 44×44 px；不会将原来的宽屏界面整体缩小。800×480 Korvo 布局仍受支持。Mosaico 顶部 Wi-Fi/时间两侧内收 60 px，主体两侧保留 32 px，底部控制上移避开圆角遮挡；首页入口采用单行“开始翻译 >”。

首页显示系统时间、实际 Wi-Fi 状态和输出音量，时间未初始化时显示占位。Mosaico 页面对音量使用整行滑条，移除无硬件功能的电量占位和亮度演示控件。Korvo 宽屏保留旧版电量 `--` 和亮度演示；演示亮度不代表硬件调光。配网提示、配对码、停止确认、字幕历史和全文页面均使用屏幕的实际宽度。

- 媒体翻译接入现有 `v2vt/listen`：板载麦克风拾音，云端翻译，板载扬声器播放。默认中文 → 英文。
- 面对面使用 `listen_speak`，选择“我的语言/对方语言”后启动一场双向会话。两路 RTC 共用一次 RTM 登录和频道订阅。
- Mosaico 会议使用 `listen_speak` 与 USB 双向音频：我的语言默认中文，对方语言默认英语。电脑原声经 LISTEN 翻译后在设备喇叭播放，板载麦克风经 SPEAK 翻译后回传电脑。连接后双方可同时发言，不显示轮流发言按钮；暂停作用于两路。实时页跟随两路最新字幕并显示该句语言方向。未注册完整 USB 音频能力的 Korvo 保留预览。
- 实时页接收当前翻译会话的 RTM 原文和译文。没有文本时显示“等待字幕”；逐句修订原文与译文，文字定稿不结束会话。点击字幕进入全文，长文本可上下滚动；本次历史分页浏览最近 64 句，浏览期间不会被新句抢走位置。

面对面连接成功后默认不发送原声，显示“请选择发言语言”。底部两个语言按钮分别选择我方 `speak` 或对方 `listen`；当前方向高亮，另设暂停/继续。切向先隔离并清除本地 PCM，再恢复新方向，扬声器仅接收当前方向的译音；保留已有云 AEC 和并行采播。页面不使用字幕 final 或定时器推断译音结束。

媒体流程为：首页 → 场景入口 → 媒体设置 → 语言选择 → 连接中 → 实时翻译。连接中可取消；实时页提供暂停/继续和更多菜单。菜单可查看本次字幕、调整音量、结束翻译或结束后更换语言。停止完成以 SDK/服务端确认结果为准，再显示完成或返回设置；完成页保留本场字幕查看入口。字幕仅在内存保留，新会话接入时清空，设备重启后不恢复。

语种选择使用 SDK 公开的同一份 15 语言清单，同语种互选禁用。仅空闲时一次提交并保存完整语言对；提交接受后锁定源语言、目标语言及开始入口，收到该语言对回读或实际失败后再开放，无关音量更新和本地等待超时不会提前解锁。模式和方向提交另有完成计数回读，同一个错误的再次失败也可确认；音量与字幕刷新不会误解锁。提交未被接受时可立即重试。活动会话修改语言前先确认结束。音量滑条拖动时预览位置，松手提交一次绝对值，最终百分比取硬件回读；实体音量键继续可用。读取失败显示 `--`，控制周期会重试恢复。

暂停保留 RTC 父会话和采集方向，以原 60 ms 节奏上行静音 MIC/reference 帧；独立停止播放方向并清除 SDK 和驱动中的旧 PCM。继续前同步工作任务、清除积压并恢复播放，成功后才更新为运行。该操作保持已保存的音量，不是云端会话结束。

配网、配对码、断网、启动拒绝、停止失败、未知启动结果等真实工作流采用统一样式。点击结束立即显示结束中；清理失败允许重试结束。服务端确认 `ended` 且本地清理记录成功移除后，SDK 清除临时清理提示，UI 显示完成页；取消或结束后更改设置则返回设置页。未知启动结果禁止创建新会话。取消期间迟到的启动成功仍保留停止入口，不能由页面返回绕过待清理状态。明确拒绝、本地音频恢复和存储错误会继续显示，不因停止成功而被抹除。

SDK 公开 `mybot/mybot_ui.h` 提供有界、非阻塞、按值复制的参数命令及语言清单。语言选择直接使用该接口检查提交结果；音量、暂停和按键事件继续经现有输入工作任务转发，业务均由 SDK control owner 处理。接受入队不等于业务已完成，显示以 LCD 状态快照回读为准。旧附件代次和失效手势不能延后执行。显示和触摸由目标板驱动管理；视图只创建控件和定时器，不接管共享 I2C 或面板缓冲。

面对面实时页只跟随选中方向的最新字幕；历史与全文标注句子的语言方向。两路按可信 Agent 映射的 `(direction, stream_id, turn_id)` 配对，切换输入不会改变迟到字幕的归属。

字幕由现有 SDK control owner 合并，同一份 PSRAM 缓存同时供实时页、全文及本次历史使用。每侧最多保留 1,023 个 UTF-8 字节，超长在完整字符边界截断，并显示截断提示。暂停期间仍接收已产生的尾稿；结束后不再接收旧会话消息。字幕不从其他发送者或频道取文。

20/28/40 px Noto Sans SC 界面字库由 `scripts/generate-lvgl-font.py` 使用已登记的源字体生成，只包含静态页面与语言名称需要的字符。独立的 `scripts/generate-caption-fonts.py` 生成 20 px/2 bpp 字幕字库，覆盖 GB2312 的全部 6,763 个汉字、Latin-1 和常见中英文标点；28 px/2 bpp 译文字体覆盖 Latin-1 与常见排版标点，缺少的汉字回退到 20 px。首期字形覆盖面向默认中文 → 英文，语言选择中的 15 个音频语种不代表全部字幕字形与排版均已覆盖；生僻字及未收录文字显示缺字占位。字体保持 SIL OFL 许可；界面无需在线字体、网页脚本或图片解码器。

主机回归在 480×480 和 800×480、中英文字串下覆盖页面导航、待开放场景、语言/音量/暂停命令、迟到启动、清理/未知状态、控件删除、内存失败、字幕归并与字形；每次切页和状态回读检查控件在父容器内、交互区域不重叠且至少 44×44 px。480×480 标签和交互区域额外检查 64 px 半径圆角安全区，顶部状态栏检查 60 px 边距。`tests/media_pause` 验证媒体门控和缓冲所有权。真实服务的字幕格式、显示与触摸操作、暂停音频仍需真机验收。烧录与业务说明见[独立听译](LISTEN_TRANSLATION.zh-CN.md)。
